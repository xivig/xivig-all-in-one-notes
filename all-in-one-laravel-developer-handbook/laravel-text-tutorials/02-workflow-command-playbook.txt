================================================================================
     LARAVEL COMPLETE WORKFLOW PLAYBOOK: STEP-BY-STEP COMMAND GUIDE
================================================================================

This playbook transforms real-world terminal command history into an organized,
sequential, step-by-step developer guide. It covers the full lifecycle of a
Laravel application—from environment initialization and project scaffolding
to models, migrations, Blade views, frontend bundling, and Git version control.

STEP 1: ENVIRONMENT & TERMINAL SETUP
================================================================================
Before creating Laravel projects, ensure your development environment is ready.

1. Verify installed software versions:
   php -v
   composer -v
   node -v
   npm -v
   git --version

2. (Optional) Configure terminal / shell environment (.bashrc or .zshrc):
   touch ~/.bashrc
   touch ~/.bash_profile


================================================================================
STEP 2: PROJECT CREATION & INITIAL SERVER SPIN-UP
================================================================================

1. Create a new Laravel project:
   --- Option A: Using Composer (Recommended) ---
   composer create-project laravel/laravel my_project

   --- Option B: Using Laravel Installer CLI ---
   laravel new my_project

2. Navigate into your project directory:
   cd my_project

3. Start the local PHP development server:
   php artisan serve

   * Application will be live at: http://127.0.0.1:8000
   * To specify a custom port:
     php artisan serve --port=8080


================================================================================
STEP 3: ENVIRONMENT CONFIGURATION, KEY & DATABASE MIGRATIONS
================================================================================

1. Ensure the `.env` file exists (copy from `.env.example` if needed):
   cp .env.example .env

2. Generate the unique application encryption key:
   php artisan key:generate --ansi

3. Configure your database in `.env` (MySQL or SQLite):
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=my_project_db
   DB_USERNAME=root
   DB_PASSWORD=

4. Run database migrations:
   php artisan migrate

5. Common Migration Management Commands:
   php artisan migrate                     # Run pending migrations
   php artisan migrate:rollback --step=1   # Rollback the last migration batch
   php artisan migrate:reset               # Rollback all application migrations
   php artisan migrate:refresh             # Rollback all migrations and run them again
   php artisan migrate:fresh               # Drop all tables and re-run all migrations
   php artisan migrate:fresh --seed        # Drop all tables, re-run migrations, and run seeders

   * Running a specific migration file:
   php artisan migrate --path=/database/migrations/2024_11_29_141302_create_categories_table.php


================================================================================
STEP 4: SCAFFOLDING BLADE LAYOUTS, PARTIALS & ANONYMOUS COMPONENTS
================================================================================

1. Create Base Blade Layout Views:
   php artisan make:view layouts.admin-layout
   php artisan make:view layouts.user-layout
   php artisan make:view layouts.home-layout
   php artisan make:view layouts.blog-layout

   Files generated in: `resources/views/layouts/`

2. Create Reusable Partials (Headers, Footers, Sidebars):
   php artisan make:view partials.admin.header
   php artisan make:view partials.admin.sidebar
   php artisan make:view partials.admin.footer
   php artisan make:view partials.user.header
   php artisan make:view partials.user.sidebar
   php artisan make:view partials.user.footer

   Files generated in: `resources/views/partials/`

3. Create Blade Components:
   --- Anonymous Component (View-only, no PHP class) ---
   php artisan make:component layouts.front --view
   php artisan make:component forms.input --view
   php artisan make:component forms.button --view

   Usage in Blade: `<x-layouts.front>...</x-layouts.front>`

   --- Class-based Component (with PHP logic class) ---
   php artisan make:component AdminLayout
   php artisan make:component UserLayout

   Files generated in:
   - `app/View/Components/AdminLayout.php`
   - `resources/views/components/admin-layout.blade.php`


================================================================================
STEP 5: GENERATING MODELS, MIGRATIONS, CONTROLLERS & FACTORIES
================================================================================

1. Basic Model:
   php artisan make:model Product

2. Model with Migration:
   php artisan make:model Product -m

3. Model with Migration & Basic Controller:
   php artisan make:model Contact -mc

4. Model with Migration & Resource Controller (CRUD actions):
   php artisan make:model Category -mcr
   php artisan make:model Post -mcr

5. Model with Controller placed inside a Sub-namespace (e.g., Admin/):
   php artisan make:model Teacher -m --controller="Admin/TeacherController" --resource
   php artisan make:controller Admin/PageController --resource

6. Model with EVERYTHING (Migration, Controller, Resource, Factory, Seeder):
   php artisan make:model Author -mcr -f -s
   php artisan make:model Comment -mcr -f -s
   php artisan make:model Tag -mcr -f -s
   php artisan make:model Picture -mcr -f -s

7. All-in-one shortcut (-a flag for All: migration, seeder, factory, policy, resource controller):
   php artisan make:model Picture -a

8. Single Action (Invokable) Controller:
   php artisan make:controller ProcessPaymentController --invokable


================================================================================
STEP 6: DATABASE SEEDERS & POPULATING SAMPLE DATA
================================================================================

1. Create Model Factories:
   php artisan make:factory CategoryFactory
   php artisan make:factory PostFactory
   php artisan make:factory CommentFactory

2. Create Database Seeders:
   php artisan make:seeder UserSeeder
   php artisan make:seeder CategorySeeder

3. Execute Database Seeders:
   php artisan db:seed                                   # Run DatabaseSeeder
   php artisan db:seed --class=CategorySeeder            # Run a specific seeder
   php artisan migrate:fresh --seed                      # Fresh migration + full seed
   php artisan db:seed --force                           # Force seeding in production


================================================================================
STEP 7: INSPECTING ROUTES & ARTISAN MAINTENANCE
================================================================================

1. Inspect Registered Application Routes:
   php artisan route:list                                # View all routes
   php artisan route:list --path=admin                   # Filter routes matching "admin"
   php artisan route:list --except-vendor                # Exclude third-party vendor routes

2. Cache & Optimization Management:
   php artisan optimize:clear                            # Clear all application caches
   php artisan config:clear                              # Clear configuration cache
   php artisan route:clear                               # Clear route cache
   php artisan view:clear                                # Clear compiled Blade views
   php artisan cache:clear                               # Clear application data cache

3. Create Storage Symbolic Link (for public file uploads):
   php artisan storage:link


================================================================================
STEP 8: FRONTEND ASSET PIPELINE (NPM, TAILWIND CSS & VITE)
================================================================================

1. Install Node Dependencies:
   npm install

2. Install and Initialize Tailwind CSS:
   npm install -D tailwindcss postcss autoprefixer
   npx tailwindcss init -p

3. Build and Watch Front-end Assets:
   --- For Local Development (Vite Hot Module Reloading) ---
   npm run dev

   --- For Production Deployment (Minified build) ---
   npm run build

4. Troubleshooting Node/NPM Issues (Corrupted packages or dependency mismatch):
   rm -rf node_modules package-lock.json
   npm cache clean --force
   npm install
   npm audit fix


================================================================================
STEP 9: INSTALLING POPULAR COMMUNITY PACKAGES
================================================================================

1. Starter Authentication Kits:
   composer require laravel/breeze --dev
   php artisan breeze:install

   composer require laravel/jetstream
   php artisan jetstream:install livewire

2. Developer & Seeding Tools:
   composer require matusstafura/faker-commerce --dev

3. Frontend JavaScript UI Libraries (via NPM):
   npm install d3
   npm install ckeditor4
   npm install @popperjs/core
   npm install alpinejs


================================================================================
STEP 10: GIT VERSION CONTROL & DEPLOYMENT WORKFLOW
================================================================================

1. Initialize Git Repository:
   git init

2. Set User Identity (if not set globally):
   git config --global user.name "Your Name"
   git config --global user.email "you@example.com"

3. (Windows specific) Resolve Git Safe Directory warning:
   git config --global --add safe.directory "D:/0.ProjectAll/laravel_all/my_project"

4. Stage and Commit Code:
   git status
   git add .
   git commit -m "Initial commit of Laravel application"

5. Link Remote Repository & Push:
   git remote add origin https://github.com/username/my-laravel-repo.git
   git branch -M main
   git push -u origin main

6. Ongoing Development Workflow:
   git pull origin main                 # Pull latest changes
   git add .                            # Stage changed files
   git commit -m "Added admin crud"     # Commit with message
   git push origin main                 # Push to remote repository

STEP 11: ESSENTIAL ARTISAN FLAGS & SHORTCUTS REFERENCE
================================================================================

Flag    Description                          Example
--------------------------------------------------------------------------------
-m      Create migration                     php artisan make:model Item -m
-c      Create controller                    php artisan make:model Item -c
-r      Make controller resource-based       php artisan make:controller ItemController -r
-f      Create factory                       php artisan make:model Item -f
-s      Create seeder                        php artisan make:model Item -s
-a      Create All (migration, seeder,       php artisan make:model Item -a
        factory, policy, controller)
--view  Create view-only anonymous component php artisan make:component card --view
--ansi  Force ANSI output color formatting   php artisan key:generate --ansi
--force Force execution in production mode   php artisan migrate --force
