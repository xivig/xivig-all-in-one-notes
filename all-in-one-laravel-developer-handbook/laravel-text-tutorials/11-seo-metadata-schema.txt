1. TECHNICAL SEO ARCHITECTURE & HEAD STANDARDS
================================================================================
Modern Google search ranking requires strict technical standards:
- Title Tags: Unique per page, 50-60 characters, with brand branding (e.g., `Page Title - BrandName`).
- Meta Descriptions: Compelling summaries, 140-155 characters.
- Canonical Links: Prevent duplicate content penalties (e.g., when parameters or trailing slashes exist).
- Viewport & Encoding: Explicit UTF-8, responsive viewport settings.
- Social Graph Tags: OpenGraph (Facebook/LinkedIn) and Twitter Cards for high click-through rates.
- JSON-LD Structured Data: Direct machine-readable entity schemas recognized by Google Rich Results.

2. BUILDING THE DYNAMIC BLADE SEO COMPONENT (<x-seo-head />)
================================================================================
Create `resources/views/components/seo-head.blade.php`:

```html
@props([
    'title' => config('app.name', 'Laravel Enterprise'),
    'description' => 'Enterprise web application built with high-performance Laravel framework architecture.',
    'keywords' => 'Laravel, PHP, Web Development, SEO, Enterprise',
    'image' => asset('images/og-default.jpg'),
    'type' => 'website',
    'canonical' => url()->current(),
    'publishedAt' => null,
    'author' => config('app.name'),
    'noindex' => false,
])

@php
    $fullTitle = $title === config('app.name') ? $title : "{$title} - " . config('app.name');
    $cleanDesc = Str::limit(strip_tags($description), 155);
@endphp

<!-- Primary Meta Tags -->
<title>{{ $fullTitle }}</title>
<meta name="title" content="{{ $fullTitle }}" />
<meta name="description" content="{{ $cleanDesc }}" />
<meta name="keywords" content="{{ $keywords }}" />
<meta name="author" content="{{ $author }}" />
<link rel="canonical" href="{{ $canonical }}" />

@if($noindex || app()->environment('local', 'staging'))
    <meta name="robots" content="noindex, nofollow" />
@else
    <meta name="robots" content="index, follow, max-snippet:-1, max-image-preview:large, max-video-preview:-1" />
@endif

<!-- Open Graph / Facebook / LinkedIn -->
<meta property="og:type" content="{{ $type }}" />
<meta property="og:url" content="{{ $canonical }}" />
<meta property="og:title" content="{{ $fullTitle }}" />
<meta property="og:description" content="{{ $cleanDesc }}" />
<meta property="og:image" content="{{ $image }}" />
<meta property="og:site_name" content="{{ config('app.name') }}" />
<meta property="og:locale" content="{{ str_replace('_', '-', app()->getLocale()) }}" />

@if($publishedAt)
    <meta property="article:published_time" content="{{ $publishedAt }}" />
    <meta property="article:author" content="{{ $author }}" />
@endif

<!-- Twitter Cards -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:url" content="{{ $canonical }}" />
<meta name="twitter:title" content="{{ $fullTitle }}" />
<meta name="twitter:description" content="{{ $cleanDesc }}" />
<meta name="twitter:image" content="{{ $image }}" />
```

Usage in your master layout (`resources/views/layouts/app.blade.php`):
```html
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Injected SEO Head -->
    <x-seo-head
        :title="$seoTitle ?? config('app.name')"
        :description="$seoDesc ?? null"
        :image="$seoImage ?? null"
        :canonical="$seoCanonical ?? null"
    />

    @vite(['resources/css/app.css', 'resources/js/app.js'])
</head>
```

3. STRUCTURED DATA (JSON-LD) SCHEMAS
================================================================================
JSON-LD allows Google to understand organizations, articles, and navigation hierarchies.

Create `resources/views/components/schema-org.blade.php`:
```html
@props([
    'type' => 'WebPage',
    'name' => config('app.name'),
    'description' => '',
    'url' => url()->current(),
    'breadcrumbs' => [],
    'article' => null,
])

<!-- WebSite & Organization Root Schema -->
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Organization",
      "@id": "{{ url('/') }}/#organization",
      "name": "{{ config('app.name') }}",
      "url": "{{ url('/') }}",
      "logo": {
        "@type": "ImageObject",
        "url": "{{ asset('images/logo.png') }}"
      }
    },
    {
      "@type": "WebSite",
      "@id": "{{ url('/') }}/#website",
      "url": "{{ url('/') }}",
      "name": "{{ config('app.name') }}",
      "publisher": { "@id": "{{ url('/') }}/#organization" },
      "potentialAction": {
        "@type": "SearchAction",
        "target": "{{ url('/search') }}?q={search_term_string}",
        "query-input": "required name=search_term_string"
      }
    }
    @if(!empty($breadcrumbs))
    ,
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        @foreach($breadcrumbs as $index => $crumb)
        {
          "@type": "ListItem",
          "position": {{ $index + 1 }},
          "name": "{{ $crumb['name'] }}",
          "item": "{{ $crumb['url'] }}"
        }{{ !$loop->last ? ',' : '' }}
        @endforeach
      ]
    }
    @endif
    @if($article)
    ,
    {
      "@type": "BlogPosting",
      "headline": "{{ $article['title'] }}",
      "description": "{{ $article['description'] }}",
      "image": "{{ $article['image'] }}",
      "datePublished": "{{ $article['published_at'] }}",
      "dateModified": "{{ $article['updated_at'] }}",
      "author": {
        "@type": "Person",
        "name": "{{ $article['author'] }}"
      },
      "publisher": { "@id": "{{ url('/') }}/#organization" },
      "mainEntityOfPage": {
        "@type": "WebPage",
        "@id": "{{ $url }}"
      }
    }
    @endif
  ]
}
</script>
```

4. AUTOMATED DYNAMIC XML SITEMAP GENERATOR (/sitemap.xml)
================================================================================
Instead of manual static XML files, generate a dynamic, high-speed sitemap
cached for 24 hours.

Create `app/Http/Controllers/SitemapController.php`:
php artisan make:controller SitemapController

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Response;
use Illuminate\Support\Facades\Cache;

class SitemapController extends Controller
{
    public function index(): Response
    {
        $xml = Cache::remember('site_sitemap_xml', 86400, function () {
            // Static core pages
            $urls = [
                ['loc' => url('/'), 'lastmod' => now()->toAtomString(), 'changefreq' => 'daily', 'priority' => '1.0'],
                ['loc' => url('/about'), 'lastmod' => now()->toAtomString(), 'changefreq' => 'monthly', 'priority' => '0.8'],
                ['loc' => url('/contact'), 'lastmod' => now()->toAtomString(), 'changefreq' => 'monthly', 'priority' => '0.7'],
            ];

            // Dynamic CMS pages (e.g. from Page model)
            if (class_exists(\App\Models\Page::class)) {
                $pages = \App\Models\Page::where('is_published', true)->get(['slug', 'updated_at']);
                foreach ($pages as $p) {
                    $urls[] = [
                        'loc' => url('/' . $p->slug),
                        'lastmod' => $p->updated_at->toAtomString(),
                        'changefreq' => 'weekly',
                        'priority' => '0.8',
                    ];
                }
            }

            // Build XML structure
            $output = '<?xml version="1.0" encoding="UTF-8"?>';
            $output .= '<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">';
            foreach ($urls as $u) {
                $output .= '<url>';
                $output .= '<loc>' . htmlspecialchars($u['loc']) . '</loc>';
                $output .= '<lastmod>' . $u['lastmod'] . '</lastmod>';
                $output .= '<changefreq>' . $u['changefreq'] . '</changefreq>';
                $output .= '<priority>' . $u['priority'] . '</priority>';
                $output .= '</url>';
            }
            $output .= '</urlset>';

            return $output;
        });

        return response($xml, 200, ['Content-Type' => 'application/xml']);
    }
}
```

Register route in `routes/web.php`:
```php
Route::get('/sitemap.xml', [\App\Http\Controllers\SitemapController::class, 'index'])->name('sitemap');
```

5. DYNAMIC ROBOTS.TXT CONTROLLER & CRAWLER RULES
================================================================================
Create a dynamic `robots.txt` route that prevents staging indexing while
exposing the sitemap URL automatically.

In `routes/web.php`:
```php
Route::get('/robots.txt', function () {
    $sitemapUrl = route('sitemap');

    if (app()->environment('production')) {
        $content = <<<ROBOTS
        User-agent: *
        Allow: /
        Disallow: /admin/
        Disallow: /login
        Disallow: /register
        Disallow: /password/

        Sitemap: {$sitemapUrl}
        ROBOTS;
    } else {
        // Disallow all crawlers on staging, local, and testing environments
        $content = <<<ROBOTS
        User-agent: *
        Disallow: /
        ROBOTS;
    }

    return response($content, 200, ['Content-Type' => 'text/plain']);
});
```

Add to `.env`:
```env
GA4_MEASUREMENT_ID="G-XXXXXXXXXX"
```

In `resources/views/partials/analytics.blade.php`:
```html
@if(app()->environment('production') && env('GA4_MEASUREMENT_ID'))
    <!-- Google tag (gtag.js) -->
    <script async src="https://www.googletagmanager.com/gtag/js?id={{ env('GA4_MEASUREMENT_ID') }}"></script>
    <script>
      window.dataLayer = window.dataLayer || [];
      function gtag(){dataLayer.push(arguments);}
      gtag('js', new Date());
      gtag('config', '{{ env('GA4_MEASUREMENT_ID') }}');
    </script>
@endif
```

7. SEO MIDDLEWARE FOR AUTOMATIC META INJECTION
================================================================================
Create `app/Http/Middleware/SeoDefaultsMiddleware.php`:
php artisan make:middleware SeoDefaultsMiddleware

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\View;

class SeoDefaultsMiddleware
{
    public function handle(Request $request, Closure $next)
    {
        // Share standard canonical URL with all views
        View::share('seoCanonical', $request->url());

        return $next($request);
    }
}
```

Register globally in `bootstrap/app.php`:
```php
->withMiddleware(function (Middleware $middleware) {
    $middleware->web(append: [
        \App\Http\Middleware\SeoDefaultsMiddleware::class,
    ]);
})
```
