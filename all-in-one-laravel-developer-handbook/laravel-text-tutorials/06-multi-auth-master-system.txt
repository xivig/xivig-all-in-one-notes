PART 1: ARCHITECTURE OVERVIEW & PREREQUISITES
================================================================================
Laravel's authentication system is built around Guards and Providers:
- Guards determine how users are authenticated for each request (e.g., 'session' driver uses cookies/sessions).
- Providers define how users are retrieved from your persistent storage (e.g., 'eloquent' driver queries the User or Admin model).

In this setup:
- 'web' guard -> session driver -> 'users' provider -> App\Models\User
- 'admin' guard -> session driver -> 'admins' provider -> App\Models\Admin

Because they use different guards and session keys, an Admin and a User can be
logged in simultaneously on the same browser without conflicting!

PART 2: USER AUTHENTICATION SETUP & EMAIL VERIFICATION
================================================================================

1. Enable Email Verification on User Model:
Open `app/Models/User.php`:
- Implement `MustVerifyEmail` contract:

<?php

namespace App\Models;

use Illuminate\Contracts\Auth\MustVerifyEmail;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;

class User extends Authenticatable implements MustVerifyEmail
{
    /** @use HasFactory<\Database\Factories\UserFactory> */
    use HasFactory, Notifiable;

    protected $fillable = [
        'name',
        'email',
        'password',
    ];

    protected $hidden = [
        'password',
        'remember_token',
    ];

    protected function casts(): array
    {
        return [
            'email_verified_at' => 'datetime',
            'password' => 'hashed',
        ];
    }
}


2. Customize Standard User Logout Redirection:
If using Laravel Breeze or standard auth controllers, open
`app/Http/Controllers/Auth/AuthenticatedSessionController.php`:

    public function destroy(Request $request): RedirectResponse
    {
        Auth::guard('web')->logout();

        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect('/login');
    }

PART 3: ADMIN DATABASE MIGRATION & MODEL GENERATION
================================================================================

1. Run the Artisan command to create Admin model, migration, controller, factory, and seeder:
php artisan make:model Admin -mcr -f -s

Flags:
-m: Migration
-c: Controller (app/Http/Controllers/AdminController.php or Admin/AdminController.php)
-r: Resource methods
-f: Model factory (database/factories/AdminFactory.php)
-s: Database seeder (database/seeders/AdminSeeder.php)


2. Define the Admins Database Migration:
Open `database/migrations/xxxx_create_admins_table.php`:

<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::create('admins', function (Blueprint $table) {
            $table->id();
            $table->string('name');
            $table->string('email')->unique();
            $table->timestamp('email_verified_at')->nullable();
            $table->string('password');
            $table->string('phone')->nullable();
            $table->string('avatar')->nullable();
            $table->rememberToken();
            $table->timestamps();
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('admins');
    }
};


3. Configure the Admin Eloquent Model:
Open `app/Models/Admin.php`:

<?php

namespace App\Models;

use Database\Factories\AdminFactory;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;

class Admin extends Authenticatable

    use HasFactory, Notifiable;

    /**
     * The table associated with the model.
     */
    protected $table = 'admins';

    /**
     * Default guard for this model.
     */
    protected $guard = 'admin';

    /**
     * The attributes that are mass assignable.
     */

        'name',
        'email',
        'password',
        'phone',
        'avatar',
    ];

    /**
     * The attributes that should be hidden for serialization.
     */
    protected $hidden = [
        'password',
        'remember_token',
    ];

    /**
     * Modern attribute casting in Laravel 11/12/13.
     */
    protected function casts(): array
    {
        return [
            'email_verified_at' => 'datetime',
            'password' => 'hashed',
        ];
    }

PART 4: CONFIGURING MULTI-AUTH IN config/auth.php
================================================================================
If `config/auth.php` does not exist in your Laravel installation, publish it:
php artisan config:publish auth

Now open `config/auth.php` and configure:

1. Guards Configuration:
    'guards' => [
        'web' => [
            'driver' => 'session',
            'provider' => 'users',
        ],

        'admin' => [
            'driver' => 'session',
            'provider' => 'admins',
        ],
    ],

2. Providers Configuration:
    'providers' => [
        'users' => [
            'driver' => 'eloquent',
            'model' => env('AUTH_MODEL', App\Models\User::class),
        ],

        'admins' => [
            'driver' => 'eloquent',
            'model' => App\Models\Admin::class,
        ],
    ],

3. Passwords Configuration (Reset Brokers):
    'passwords' => [
        'users' => [
            'provider' => 'users',
            'table' => env('AUTH_PASSWORD_RESET_TOKEN_TABLE', 'password_reset_tokens'),
            'expire' => 60,
            'throttle' => 60,
        ],

        'admins' => [
            'provider' => 'admins',
            'table' => env('AUTH_PASSWORD_RESET_TOKEN_TABLE', 'password_reset_tokens'),
            'expire' => 60,
            'throttle' => 60,
        ],
    ],

PART 6: ADMIN MIDDLEWARES (PROTECTION & GUEST REDIRECTION)
================================================================================

We need TWO dedicated middlewares:
1. `AdminAuthenticate`: Protects admin dashboard from unauthenticated guests.
2. `AdminRedirectIfAuthenticated`: Prevents already logged-in admins from viewing the login form.

1. Generate Middlewares:
php artisan make:middleware AdminAuthenticate
php artisan make:middleware AdminRedirectIfAuthenticated


2. Open `app/Http/Middleware/AdminAuthenticate.php`:
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Symfony\Component\HttpFoundation\Response;

class AdminAuthenticate
{
    public function handle(Request $request, Closure $next): Response
    {
        if (! Auth::guard('admin')->check()) {
            return redirect()->route('admin.login')
                ->with('error', 'Please login to access the admin panel.');
        }

        return $next($request);
    }
}


3. Open `app/Http/Middleware/AdminRedirectIfAuthenticated.php`:
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Symfony\Component\HttpFoundation\Response;

class AdminRedirectIfAuthenticated
{
    public function handle(Request $request, Closure $next): Response
    {
        if (Auth::guard('admin')->check()) {
            return redirect()->route('admin.dashboard');
        }

        return $next($request);
    }
}

PART 7: REGISTERING MIDDLEWARES IN bootstrap/app.php
================================================================================
In Laravel 11/12/13, register the middleware aliases in `bootstrap/app.php`:

<?php

use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        api: __DIR__.'/../routes/api.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware) {
        $middleware->alias([
            'admin.auth'  => \App\Http\Middleware\AdminAuthenticate::class,
            'admin.guest' => \App\Http\Middleware\AdminRedirectIfAuthenticated::class,
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions) {
        //
    })->create();

PART 8: AdminController IMPLEMENTATION (Login, Dashboard, Logout)
================================================================================
Create or replace `app/Http/Controllers/Admin/AdminController.php`:

<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\View\View;

class AdminController extends Controller
{
    /**
     * Show Admin Login Form.
     */
    public function login(): View
    {
        return view('admin.login');
    }

    /**
     * Handle Admin Login Submission.
     */
    public function loginSubmit(Request $request): RedirectResponse
    {
        $credentials = $request->validate([
            'email'    => ['required', 'email'],
            'password' => ['required', 'string'],
        ]);

        $remember = $request->boolean('remember');

        if (Auth::guard('admin')->attempt($credentials, $remember)) {
            $request->session()->regenerate();

            return redirect()->intended(route('admin.dashboard'))
                ->with('success', 'Welcome to Admin Dashboard!');
        }

        return back()
            ->withInput($request->only('email', 'remember'))
            ->withErrors([
                'email' => 'The provided credentials do not match our admin records.',
            ]);
    }

    /**
     * Show Admin Dashboard.
     */
    public function dashboard(): View
    {
        $admin = Auth::guard('admin')->user();
        return view('admin.dashboard', compact('admin'));
    }

    /**
     * Handle Admin Logout.
     */
    public function logout(Request $request): RedirectResponse
    {
        Auth::guard('admin')->logout();

        $request->session()->invalidate();
        $request->session()->regenerateToken();

        return redirect()->route('admin.login')
            ->with('success', 'You have been logged out successfully.');
    }
}

PART 9: DEFINING MULTI-AUTH ROUTES IN routes/web.php
================================================================================
Open `routes/web.php` and define user routes and admin routes:

<?php

use App\Http\Controllers\Admin\AdminController;
use Illuminate\Support\Facades\Route;

// -----------------------------------------------------------------------------
// Public / User Routes
// -----------------------------------------------------------------------------
Route::get('/', function () {
    return view('welcome');
});

Route::middleware(['auth:web', 'verified'])->group(function () {
    Route::get('/dashboard', function () {
        return view('dashboard');
    })->name('dashboard');
});

// -----------------------------------------------------------------------------
// Admin Guest Routes (Login Page & Submission)
// -----------------------------------------------------------------------------
Route::prefix('admin')->name('admin.')->group(function () {
    Route::middleware(['web', 'admin.guest'])->group(function () {
        Route::get('/login', [AdminController::class, 'login'])->name('login');
        Route::post('/login', [AdminController::class, 'loginSubmit'])->name('login.submit');
    });

    // -------------------------------------------------------------------------
    // Admin Authenticated Routes (Dashboard, Logout)
    // -------------------------------------------------------------------------
    Route::middleware(['web', 'admin.auth'])->group(function () {
        Route::get('/dashboard', [AdminController::class, 'dashboard'])->name('dashboard');
        Route::post('/logout', [AdminController::class, 'logout'])->name('logout');
    });
});

PART 11: ADMIN PASSWORD RESET (USING 'admins' PASSWORD BROKER)
================================================================================
If your application requires separate password reset emails for Admins:

1. Request password reset link in Controller:
use Illuminate\Support\Facades\Password;

$status = Password::broker('admins')->sendResetLink(
    $request->only('email')
);

2. Reset Admin Password in Controller:
$status = Password::broker('admins')->reset(
    $request->only('email', 'password', 'password_confirmation', 'token'),
    function ($admin, $password) {
        $admin->forceFill([
            'password' => Hash::make($password)
        ])->setRememberToken(Str::random(60));

        $admin->save();
    }
);

PART 13: OPTIONAL EMAIL OTP TWO-FACTOR AUTHENTICATION FOR ADMINS
================================================================================
For high-security enterprise applications, you can enforce an email-based One-Time
Password (OTP) verification step whenever an Administrator logs in.

1. Add OTP columns to admins table:
php artisan make:migration add_otp_columns_to_admins_table --table=admins

Update migration:
```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    public function up(): void
    {
        Schema::table('admins', function (Blueprint $table) {
            $table->string('email_otp', 6)->nullable()->after('password');
            $table->timestamp('otp_expires_at')->nullable()->after('email_otp');
        });
    }

    public function down(): void
    {
        Schema::table('admins', function (Blueprint $table) {
            $table->dropColumn(['email_otp', 'otp_expires_at']);
        });
    }
};
```
Run migration:
php artisan migrate

2. Generate OTP Mailable:
php artisan make:mail AdminOtpMail

In `app/Mail/AdminOtpMail.php`:

```php
<?php

namespace App\Mail;

use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;

class AdminOtpMail extends Mailable
{
    use Queueable, SerializesModels;

    public function __construct(public string $otp) {}

    public function envelope(): Envelope
    {
        return new Envelope(subject: 'Your Admin Login Verification Code');
    }

    public function content(): Content
    {
        return new Content(view: 'emails.admin-otp');
    }
}
```

4. Create `AdminOtpController`:
php artisan make:controller Admin/AdminOtpController

In `app/Http/Controllers/Admin/AdminOtpController.php`:
```php
<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Mail\AdminOtpMail;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Mail;

class AdminOtpController extends Controller
{
    public function showVerifyForm()
    {
        if (!session()->has('admin_otp_pending')) {
            return redirect()->route('admin.login');
        }

        return view('admin.auth.verify-otp');
    }

    public function verify(Request $request)
    {
        $request->validate([
            'otp' => ['required', 'string', 'size:6'],
        ]);

        $adminId = session('admin_otp_pending');
        $admin = \App\Models\Admin::find($adminId);

        if (!$admin || $admin->email_otp !== $request->otp) {
            return back()->withErrors(['otp' => 'The entered verification code is incorrect.']);
        }

        if (now()->isAfter($admin->otp_expires_at)) {
            return back()->withErrors(['otp' => 'The verification code has expired. Please request a new one.']);
        }

        // Clear OTP & mark authenticated
        $admin->update([
            'email_otp' => null,
            'otp_expires_at' => null,
        ]);

        session()->forget('admin_otp_pending');
        Auth::guard('admin')->login($admin);
        $request->session()->regenerate();

        return redirect()->intended(route('admin.dashboard'));
    }

    public function resend(Request $request)
    {
        $adminId = session('admin_otp_pending');
        $admin = \App\Models\Admin::find($adminId);

        if (!$admin) {
            return redirect()->route('admin.login');
        }

        $otp = sprintf("%06d", random_int(100000, 999999));
        $admin->update([
            'email_otp' => $otp,
            'otp_expires_at' => now()->addMinutes(10),
        ]);

        Mail::to($admin->email)->send(new AdminOtpMail($otp));

        return back()->with('status', 'A new verification code has been sent to your email.');
    }
}
```
