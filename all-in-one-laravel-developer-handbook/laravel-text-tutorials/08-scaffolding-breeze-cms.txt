1. LARAVEL BREEZE AUTHENTICATION SETUP & FRONTEND STACKS
================================================================================
Laravel Breeze provides a minimal, clean, and robust starting point for building
authentication into your application with Tailwind CSS.

Step 1: Install Breeze package via Composer:
composer require laravel/breeze --dev

Step 2: Run the Breeze installation command:
php artisan breeze:install

When prompted, select your preferred stack:
- blade       : Traditional server-rendered Blade templates (Default)
- livewire    : Reactive UI with Livewire and Volt
- vue         : Inertia.js with Vue 3
- react       : Inertia.js with React
- api         : API only (Headless with Laravel Sanctum)

You can also specify options directly:
php artisan breeze:install blade --dark --pest
php artisan breeze:install livewire --dark

Step 3: Run database migrations and compile frontend assets:
php artisan migrate
npm install
npm run dev

* For production deployment:
npm run build

4. DYNAMIC CMS PAGE CONTENT MANAGEMENT & CACHING SYSTEM
================================================================================
When website pages (About, Services, Privacy, Terms, FAQ) share the same layout
and store their content in the database, implement a unified dynamic controller:

--------------------------------------------------------------------------------
Step 1: Pages Database Schema
--------------------------------------------------------------------------------
Open `database/migrations/xxxx_create_pages_table.php`:

Schema::create('pages', function (Blueprint $table) {
    $table->id();
    $table->string('title');
    $table->string('slug')->unique();
    $table->text('content');
    $table->string('meta_title')->nullable();
    $table->string('meta_description')->nullable();
    $table->boolean('is_active')->default(true);
    $table->timestamps();
});

--------------------------------------------------------------------------------
Step 2: Page Controller with High-Performance Caching
--------------------------------------------------------------------------------
Open `app/Http/Controllers/PageController.php`:

<?php

namespace App\Http\Controllers;

use App\Models\Page;
use Illuminate\Support\Facades\Cache;
use Illuminate\View\View;

class PageController extends Controller
{
    /**
     * Display a dynamic CMS page by slug.
     */
    public function show(string $slug): View
    {
        // Cache static page content for 24 hours to eliminate repetitive DB queries:
        $page = Cache::remember("page_{$slug}", now()->addHours(24), function () use ($slug) {
            return Page::where('slug', $slug)
                       ->where('is_active', true)
                       ->firstOrFail();
        });

        return view('pages.show', compact('page'));
    }
}

--------------------------------------------------------------------------------
Step 3: Define Dynamic Route in routes/web.php
--------------------------------------------------------------------------------
Place this route near the bottom of `routes/web.php`:

use App\Http\Controllers\PageController;

Route::get('/page/{slug}', [PageController::class, 'show'])->name('page.show');

--------------------------------------------------------------------------------
Step 4: Reusable Page Blade Template (resources/views/pages/show.blade.php)
--------------------------------------------------------------------------------
@extends('layouts.home-layout')

@section('title', $page->meta_title ?? $page->title)

@section('content')
<div class="container mx-auto px-4 py-12 max-w-4xl">
    <article class="prose lg:prose-xl bg-white p-8 rounded-lg shadow">
        <h1 class="text-3xl font-bold text-gray-900 mb-6">{{ $page->title }}</h1>
        <div class="page-body text-gray-700 leading-relaxed">
            {!! $page->content !!}
        </div>
    </article>
</div>
@endsection

5. PAGINATION INDEXING, TIMEZONES & BLADE PRACTICAL HELPERS
================================================================================

--------------------------------------------------------------------------------
1. Continuous Pagination Row Indexing Formula:
--------------------------------------------------------------------------------
When using pagination (`$products->paginate(10)`), `$loop->iteration` resets to 1
on every page. To display continuous row numbers (e.g. 1-10 on page 1, 11-20 on page 2):

<tbody>
    @foreach ($products as $product)
        @php
            $rowNumber = $loop->iteration + $products->firstItem() - 1;
        @endphp
        <tr>
            <th scope="row">{{ $rowNumber }}</th>
            <td>{{ $product->name }}</td>
            <td>${{ number_format($product->price, 2) }}</td>
        </tr>
    @endforeach
</tbody>

--------------------------------------------------------------------------------
2. Setting Default Application Timezone:
--------------------------------------------------------------------------------
Open `config/app.php`:
'timezone' => 'Asia/Kolkata',

In Laravel 11/12/13, set in `.env`:
APP_TIMEZONE=Asia/Kolkata

6. DATABASE MANAGEMENT, MIGRATIONS & SEEDERS
================================================================================

1. Run all migrations:
   php artisan migrate

2. Fresh migration (drops all tables) and seeds database:
   php artisan migrate:fresh --seed

3. Run a specific database seeder:
   php artisan db:seed --class=FooterSeeder
   php artisan db:seed --class=PageSeeder

4. Create public storage symlink for uploaded files:
   php artisan storage:link

5. Rollback or refresh migrations:
   php artisan migrate:rollback
   php artisan migrate:refresh


================================================================================
7. APPLICATION CACHE CLEARING & OPTIMIZATION MAINTENANCE
================================================================================

1. Clear all application caches in development:
   php artisan optimize:clear

2. Individual cache clearing commands:
   php artisan cache:clear          # Application data cache
   php artisan config:clear         # Configuration cache
   php artisan route:clear          # Route registration cache
   php artisan view:clear           # Compiled Blade templates cache

3. Inspect application routes:
   php artisan route:list

4. Run local server:
   php artisan serve

5. Build production optimized caches:
   php artisan optimize             # Caches config, routes, and views for production
