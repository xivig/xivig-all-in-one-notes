1. AUTHENTICATION & SECURITY CHECKLIST
================================================================================

[ ] 1. Authentication Flows Completed:
    [ ] Login (`/login`) with rate limiting (throttling)
    [ ] Registration (`/register`) with strong password rules:
        Password::min(8)->letters()->mixedCase()->numbers()->symbols()->uncompromised()
    [ ] Password Reset Request (`/forgot-password`) via signed email tokens
    [ ] Password Reset Submission (`/reset-password/{token}`)
    [ ] Email Verification (`/email/verify`) with `MustVerifyEmail` contract on User model
    [ ] Password Confirmation (`/confirm-password`) for sensitive actions
    [ ] Two-Factor Authentication (2FA) configured if using Jetstream/Fortify

[ ] 2. Multi-Guard Authentication (If Admin Panel exists):
    [ ] Separate 'admin' guard and 'admins' provider in `config/auth.php`
    [ ] Admin session isolation: Admin logout does not affect User session
    [ ] Protected routes with dedicated middleware (`admin.auth` / `admin.guest`)

[ ] 3. Security Hardening:
    [ ] CSRF Protection active on all POST/PUT/DELETE forms (`@csrf`)
    [ ] Mass Assignment Protection: Every model defines `$fillable` or `$guarded`
    [ ] SQL Injection Prevention: No unescaped variables in `DB::raw()` or `whereRaw()`
    [ ] XSS Prevention: User input rendered with `{{ $var }}` (escaped), never unescaped `{!! !!}`
    [ ] Content Security: Sanitize rich text inputs using HTMLPurifier before storage
    [ ] Secure Cookies: `SESSION_SECURE_COOKIE=true` in `.env` for HTTPS
    [ ] Rate Limiting: API and login routes protected via `throttle:60,1` or custom limiter


================================================================================
2. DATABASE, ELOQUENT & DATA INTEGRITY CHECKLIST
================================================================================

[ ] 1. Schema & Migration Integrity:
    [ ] Foreign Keys properly constrained with cascade actions:
        `$table->foreignId('user_id')->constrained()->cascadeOnDelete();`
    [ ] Indexes created on frequently queried and foreign key columns:
        `$table->index(['user_id', 'created_at']);`
    [ ] Unique constraints set on slugs, emails, and reference codes:
        `$table->string('slug')->unique();`
    [ ] Soft deletes implemented where accidental data loss must be prevented (`$table->softDeletes();`)

[ ] 2. Eloquent Performance & Guardrails:
    [ ] N+1 Query Trap Prevented: Eager load relationships using `with([...])`
    [ ] Prevent lazy loading enabled in development (`AppServiceProvider::boot()`):
        `Model::preventLazyLoading(! app()->isProduction());`
    [ ] Eloquent Strict Mode enabled in local:
        `Model::shouldBeStrict(! app()->isProduction());`
    [ ] Database Transactions used for multi-table writes (`DB::transaction(fn () => ...)`)
    [ ] Heavy batch operations use `chunkById()`, `cursor()`, or `lazy()` instead of `get()`

[ ] 3. Seeders & Factories:
    [ ] Model Factories defined for all primary models
    [ ] `DatabaseSeeder.php` populates realistic sample data for local testing
    [ ] Idempotent seeding implemented using `updateOrCreate()` or `firstOrCreate()`


================================================================================
3. BLOG & DYNAMIC CMS IMPLEMENTATION CHECKLIST
================================================================================

[ ] 1. Model Relationships:
    [ ] `Post` belongs to `User` (Author) and `Category`
    [ ] `Post` has many `Comments` and belongs to many `Tags` (via `post_tag` pivot)
    [ ] Cascading deletes configured on pivot and child tables

[ ] 2. Slug & URL Management:
    [ ] Automatic slug generation from title (`Str::slug($title)`)
    [ ] Unique slug collision handling (appending suffix if duplicate exists)
    [ ] Route model binding using slug: `Route::get('/posts/{post:slug}', ...)`

[ ] 3. Media & Uploads:
    [ ] Image uploads validated: `image`, `mimes:jpeg,png,webp`, `max:2048`
    [ ] Public storage symlink created: `php artisan storage:link`
    [ ] WebP conversion or responsive image thumbnail generation configured

[ ] 4. Publishing & Status Scopes:
    [ ] Published scope defined:
        `public function scopePublished($query) { $query->where('is_published', true)->where('published_at', '<=', now()); }`
    [ ] Draft preview capability for authenticated authors/admins

[ ] 5. Comments & Engagement:
    [ ] Comment moderation workflow (pending / approved)
    [ ] Spam protection implemented (honeypot field, rate limiting, or CAPTCHA)

4. COMPLETE LARAVEL `make:` ARTISAN COMMAND REFERENCE
================================================================================
Laravel includes code generation commands for every layer of the architecture:

Command                         Purpose & Example Usage
--------------------------------------------------------------------------------
make:model <Name>               Creates Eloquent Model
                                Options:
                                -m : include migration
                                -c : include controller
                                -r : resource controller
                                -f : include factory
                                -s : include seeder
                                -a : all of the above + policy
                                Example: `php artisan make:model Post -mcr -f -s`

make:controller <Name>          Creates HTTP Controller
                                `--resource` : CRUD methods
                                `--invokable`: Single action controller
                                `--model=Post`: Route model binding injected
                                Example: `php artisan make:controller Admin/PostController --resource --model=Post`

make:migration <name>           Creates database migration file
                                `--create=table_name` : Create new table schema
                                `--table=table_name`  : Alter existing table
                                Example: `php artisan make:migration add_avatar_to_users_table --table=users`

make:seeder <Name>              Creates database seeder in database/seeders/
                                Example: `php artisan make:seeder CategorySeeder`

make:factory <Name>             Creates model factory in database/factories/
                                Example: `php artisan make:factory ProductFactory --model=Product`

make:request <Name>             Creates Form Request validation class in app/Http/Requests/
                                Example: `php artisan make:request StorePostRequest`

make:middleware <Name>          Creates HTTP Middleware in app/Http/Middleware/
                                Example: `php artisan make:middleware CheckAdminRole`

make:component <Name>           Creates Blade UI Component
                                `--view` : Anonymous view-only component (no PHP class)
                                Example: `php artisan make:component forms.input --view`
                                Class-based: `php artisan make:component Modal`

make:view <name>                Creates Blade view template in resources/views/
                                Example: `php artisan make:view layouts.admin`

make:mail <Name>                Creates Mailable class in app/Mail/
                                `--markdown=view.path` : Markdown email template
                                Example: `php artisan make:mail OrderInvoice --markdown=emails.orders.invoice`

make:notification <Name>        Creates Notification class in app/Notifications/
                                Example: `php artisan make:notification NewCommentNotification`

make:job <Name>                 Creates Queued Job in app/Jobs/
                                Example: `php artisan make:job ProcessPodcastAudio`

make:event <Name>               Creates Event class in app/Events/
                                Example: `php artisan make:event OrderPlaced`

make:listener <Name>            Creates Event Listener in app/Listeners/
                                `--event=OrderPlaced` : Pre-binds event
                                Example: `php artisan make:listener SendOrderEmail --event=OrderPlaced`

make:policy <Name>              Creates Authorization Policy in app/Policies/
                                `--model=Post` : Pre-fills CRUD authorization methods
                                Example: `php artisan make:policy PostPolicy --model=Post`

make:rule <Name>                Creates Custom Validation Rule in app/Rules/
                                Example: `php artisan make:rule ValidPostalCode`

make:resource <Name>            Creates API Resource transformation class in app/Http/Resources/
                                Example: `php artisan make:resource UserResource`

make:command <Name>             Creates Custom CLI Artisan Command in app/Console/Commands/
                                Example: `php artisan make:command SendWeeklyNewsletter`

make:observer <Name>            Creates Model Observer in app/Observers/
                                `--model=User` : Pre-fills Eloquent lifecycle methods
                                Example: `php artisan make:observer UserObserver --model=User`

make:scope <Name>               Creates Reusable Global Eloquent Query Scope
                                Example: `php artisan make:scope ActiveScope`

make:cast <Name>                Creates Custom Eloquent Attribute Cast class
                                Example: `php artisan make:cast JsonPayload`

make:channel <Name>             Creates Broadcast Authorization Channel class
                                Example: `php artisan make:channel OrderStatusChannel`

make:exception <Name>           Creates Custom Exception class in app/Exceptions/
                                Example: `php artisan make:exception PaymentFailedException`

make:enum <Name>                Creates PHP 8.1+ Enum in app/Enums/
                                Example: `php artisan make:enum OrderStatus`

make:interface <Name>           Creates PHP Interface in app/Contracts/ or app/
                                Example: `php artisan make:interface PaymentGatewayInterface`

make:trait <Name>               Creates PHP Trait in app/Traits/
                                Example: `php artisan make:trait HasSlug`

make:class <Name>               Creates Generic Service or Action class
                                Example: `php artisan make:class Actions/CreateInvoiceAction`

make:test <Name>                Creates Test class in tests/Feature/ or tests/Unit/
                                `--unit` : Unit test
                                Example: `php artisan make:test UserAuthTest`

5. IDE OPTIMIZATION SETUP (PhpStorm & VS Code Type-Hinting)
================================================================================
When PhpStorm or VS Code highlights `create()`, `where()`, `latest()`, or Facades
as "Method not found", install and configure `laravel-ide-helper`:

Step 1: Install IDE Helper (Dev Dependency):
composer require --dev barryvdh/laravel-ide-helper

Step 2: Generate Facades PHPDoc helper:
php artisan ide-helper:generate

Step 3: Generate Model PHPDocs (Injects database schema properties into models):
php artisan ide-helper:models -N
(Select Yes to write docblocks directly to model files)

Step 4: Generate PhpStorm Meta Container File:
php artisan ide-helper:meta

Step 5: Automate in `composer.json` scripts:
Add to the `"post-update-cmd"` array in `composer.json`:
"scripts": {
    "post-update-cmd": [
        "Illuminate\\Foundation\\ComposerScripts::postUpdate",
        "@php artisan ide-helper:generate",
        "@php artisan ide-helper:meta"
    ]
}

Step 6: PhpStorm Cache Reset (If still showing warnings):
Go to: File -> Invalidate Caches... -> Select "Clear file system cache and Local History" -> Invalidate and Restart.

6. TECHNICAL SEO, METADATA & ACCESSIBILITY CHECKLIST
================================================================================

[ ] 1. Meta Tags & Header SEO:
    [ ] Unique, descriptive `<title>` tag on every single page (Format: "Page Title | Site Name")
    [ ] Meta description present and under 160 characters
    [ ] Canonical link tag defined: `<link rel="canonical" href="{{ url()->current() }}" />`
    [ ] OpenGraph / Twitter Cards meta tags (og:title, og:description, og:image, og:url)
    [ ] Favicon and apple-touch-icon included in `<head>`

[ ] 2. Semantic Content & Accessibility (WCAG):
    [ ] Single `<h1>` per page reflecting the primary topic
    [ ] Logical heading hierarchy (`<h2>`, `<h3>`, `<h4>` without skipping levels)
    [ ] Descriptive `alt` attributes on all meaningful `<img>` tags (`alt=""` for decorative)
    [ ] Form inputs have associated `<label for="...">` tags
    [ ] Adequate color contrast between text and background (minimum 4.5:1 ratio)

[ ] 3. Search Engine Indexing:
    [ ] `public/robots.txt` configured:
        User-agent: *
        Disallow: /admin/
        Disallow: /dashboard
        Sitemap: https://yourdomain.com/sitemap.xml
    [ ] XML Sitemap generated and verified (via `spatie/laravel-sitemap` or route builder)
    [ ] Structured Data (JSON-LD) added for Articles, Products, or Organizations
    [ ] Custom branded 404 error page (`resources/views/errors/404.blade.php`)

7. PRE-LAUNCH PERFORMANCE & PRODUCTION DEPLOYMENT CHECKLIST
================================================================================

[ ] 1. Environment & Security Check:
    [ ] `APP_ENV=production` set in `.env`
    [ ] `APP_DEBUG=false` (CRITICAL: Never expose debug screens with secrets in production)
    [ ] `APP_KEY` generated and verified
    [ ] `APP_URL=https://yourdomain.com` configured with correct HTTPS scheme
    [ ] Database credentials secured; root login disabled

[ ] 2. SSL/HTTPS Enforcement:
    [ ] SSL Certificate installed (Let's Encrypt / Cloudflare)
    [ ] Force HTTPS in `app/Providers/AppServiceProvider.php`:
        if ($this->app->environment('production')) {
            \Illuminate\Support\Facades\URL::forceScheme('https');
        }

[ ] 3. Asset & Production Compilation:
    [ ] Node assets compiled and minified:
        `npm run build`
    [ ] Composer autoloader optimized without dev dependencies:
        `composer install --optimize-autoloader --no-dev`

[ ] 4. Laravel Production Optimization Caches:
    [ ] Compile config cache:
        `php artisan config:cache`
    [ ] Compile route cache:
        `php artisan route:cache`
    [ ] Compile Blade template cache:
        `php artisan view:cache`
    [ ] Compile event cache:
        `php artisan event:cache`

[ ] 5. Background Services & Monitoring:
    [ ] Single Cron job configured on production server:
        `* * * * * cd /path-to-app && php artisan schedule:run >> /dev/null 2>&1`
    [ ] Queue Worker running via Supervisor or systemd:
        `php artisan queue:work --tries=3 --timeout=90`
    [ ] Log channel configured to `daily` with 14-day retention in `config/logging.php`
    [ ] Automated database backups scheduled (e.g. `spatie/laravel-backup`)
    [ ] Health check monitor pointed to `/up` endpoint
